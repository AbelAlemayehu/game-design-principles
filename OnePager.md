## Summary
This document explores game design principles that each focus on a different aspect of player immersion. Strong principles help every element of the game feel cohesive, without them, the game feels fragmented and frustrating. When applied well, the principles help unify the entire game to create a satisfying experience.

---

## Build Your Game Around a Core Mechanic
A strong game is built around a core mechanic, a single action that carries the entire experience. Instead of adding dozens of scattered features, a game should reinforce a single mechanic that a design can be centered around. Whether it's web swinging in SpiderMan, portals in Portal, racing in Mario Kart, or shooting in Call of Duty; the game's levels, enemies, and story can be designed to express the central action. In Mario Kart, the different variations of maps, the customization of the vehicles, and the different items that can be used all give the player a strong sense of mastery with the game's racing mechanic.

**Pros:**  
- Creates a focused identity so that the player associates the game with one strong experience.  
- Encourages deep mastery of the game core mechanic.  
- Players understand the game quicker so that the learning curve is on mastery, not complexity.  

**Cons:**  
- The game can loop without careful variation of the main mechanic, which can make the game repetitive.  
- Some players want diverse systems in the game, where focusing on one mechanic may be stale and boring.  
- The game can become boring in the long term when players master the core mechanic, and replay value can drop.  

**Use Case:**  
I would start with one mechanic that defines the game experience, like running. Every level and enemy would be built around the mastery of running: running from enemies and running to different places and objects. The goal is to let players feel mastery of one skill instead of juggling many all at once.

## Balance Gameplay Options
In well balanced games, players can choose how they want to play because the gameplay options allow every strategy, ability, or weapon to feel fair and viable. There shouldn’t be a single character, move, or weapon that dominates all others or makes the rest irrelevant. Ideally everything in a game should have a tradeoff where there are strengths and weaknesses for the player to master. This is extremely important in head to head fighting games like Street Fighter, UFC, Injustice, Mortal Kombat, etc., where a single broken character can ruin the variability since everyone is going to pick the same overpowered character. For example, in Injustice: Gods Among Us (2013), there were certain characters like Deathstroke that could spam gunshots from full screen, making the matches unplayable for most characters. Good balance keeps the game fun and replayable for all types of players.

**Pros:**  
- No single strategy dominated, limiting overpowered gameplay.  
- Encourages players to experiment with builds, weapons, or characters.  
- Keeps the meta shifting so that players are constantly innovating.  

**Cons:**  
- Perfect balance is impossible, so the devs patch constantly.  
- Games like League of Legends tend to overbalance, removing fun/fun broken parts of the game.  

**Use Case:**  
If I made a magic system card game like Hearthstone, I’d make sure each deck and class has clear advantages and weaknesses. A certain card might deal a lot of damage but is squishy, and another card might have great defensive stats but is offensively weak. I would balance around making the game feel accessible for all types of players so that the game is fun for all players.

## Provide a Seamless Player Experience
Providing a seamless player experience is about removing barriers between the player and the game. This depends on invisible transitions and every element, from loading to UI. GTA 5 has a long intro loading screen, which pauses the player and reminds them they are playing a game. Great design allows the player to remain fully immersed in their experience so gameplay, cutscenes, and menus should blend smoothly. Ghost of Tsushima removes UI clutter and its transitions between menu to combat; duels start instantly without hard cuts. Marvel's Spiderman allows players to swing through the city with no fade outs or load screens, and the mission transitions happen without breaking movement. The goal is to maintain player flow, where intuitive parts of the game are minimized.

**Pros:**  
- Deeper game immersion.  
- The player has reduced frustration as bloated junk is cut from the game.  
- Fewer breaks in gameplay help the player remain emotionally invested.  

**Cons:**  
- It is hard to implement some of these features in the game, which will cost an increased amount of resources some games can't allow.  

**Use Case:**  
I would design transitions to never pull players out of the moment. I would refrain from doing what GTA 5 does, where the load on the screen of the game breaks the player's immersion. Entering a building and having natural camera flow helps the user remain connected to the game.
